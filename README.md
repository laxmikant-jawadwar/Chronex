# Chronex - Premium Watch Marketplace

A microservices-based e-commerce platform for trading luxury timepieces.

## Architecture & Services
- **frontend**: Web UI
- **api-gateway**: API Gateway routing and security
- **services/**
  - `auth-service`: Authentication & Authorization
  - `product-service`: Product Catalog & Management
  - `cart-service`: Shopping Cart Management
  - `order-service`: Order Processing & Management
  - `review-service`: Product Reviews & Ratings
  - `inventory-service`: Stock & Inventory Management
  - `payment-service`: Payment Gateway Integration
  - `notification-service`: Email/SMS & Push Notifications
- **infrastructure**: Infrastructure setup & configurations
